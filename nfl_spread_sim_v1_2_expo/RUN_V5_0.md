# NFL SIM v5.0 — Current Week + Next Week Predictions

This patch keeps the v4.9.1 projected-moneyline-winner UI and adds a two-week model board.

## What changes

- Dashboard gets a Week 3 / Week 4 selector.
- Best Bets gets the same week selector.
- Week 4 is generated by the existing `score_model.multi_book_live_v31` model, not by placeholder scores.
- Week 4 cards include projected score, projected moneyline winner, spread/total picks, top two book quotes, and qualifying-edge status when those outputs are available.
- Only bets you personally tap `I BET THIS` on are tracked.
- Personal bet settlement can now read game results independently of the old shadow ledger.

## Install

Download this ZIP from ChatGPT, upload it into the repo root, then run:

```bash
cd /workspaces/nfl-spread-sim/nfl_spread_sim_v1_2_expo
unzip -o nfl_app_v5_0_current_and_next_week.zip
```

## Generate Week 4 predictions and rebuild the app data

The easiest command is:

```bash
bash score_model/refresh_week4_v50.sh
```

That runs:

```bash
python -m score_model.multi_book_live_v31 --season 2026 --week 4 --max-age-minutes 30
```

and then combines Week 3 + Week 4 into `mobile/generatedData.ts`.

## Start Expo

```bash
cd mobile
npx expo start --tunnel -c
```

## Early-week note

Week 4 can be generated before Week 3 is completely finished, but those are early projections. Re-run `bash score_model/refresh_week4_v50.sh` after Week 3 finishes so Week 4 uses the freshest available inputs and sportsbook prices.
