# App v1.1

This is the first personal-use interface for the NFL spread model.

## Main screen

Game selector:
- week
- matchup

Selected game shows:
- model projected winner/margin
- best spread
- best odds
- sportsbook
- cover probability
- break-even probability
- model probability edge
- projected differential

## Simulation area

Shows:
- 1,000,000 final simulations
- matchup volatility
- selected spread details

## Sportsbook comparison

Displays all current spread/price opportunities available in the supplied market feed.

## Top 5

Scans the selected week's loaded games and shows the best slate opportunities.

## Current limitation

The UI is working, but live data automation is not yet connected.
Weekly games, market odds, injuries/weather, and matchup feature files still
need to be populated by the upstream data pipeline.
